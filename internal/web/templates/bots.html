Add bot

Issues a bot token for the daemon. The Telegram bot token stays in the daemon's own config.

Daemon API

Authenticated with the bot token (Authorization: Bearer …):

  • POST /api/bots/register — announce name, telegram username, machine, version (idempotent)
  • POST /api/bots/heartbeat — liveness + whitelist cursor
  • GET /api/bots/chats — whitelist; updated_since + wait for long-poll
  • POST /api/bots/chats/pending — report an unknown chat (idempotent per chat)
  • GET /api/bots/deliveries — outbox (AI job results); wait for long-poll
  • POST /api/bots/deliveries/ack — confirm what was forwarded; unacked deliveries come back

MCP tools when this module is enabled: bots_list, bots_chats, bots_approve, bots_deny. Readiness is in takan_status. Full contract for daemon authors: TAKAN_BOTS.md.

Sign-in

  • Owner address: {{if .OwnerEmailMasked}}{{.OwnerEmailMasked}}{{else}}not configured{{end}}
  • Set with TAKAN_OWNER_EMAIL in the service environment; falls back to the address on the owner row.
  • Codes are 6 digits, single-use, valid 10 minutes, stored salted-hashed. Issuing a new one invalidates the previous.
  • Sending uses the stored Resend key directly, so login keeps working even if the Email module is toggled off. Override the From address with TAKAN_AUTH_EMAIL_FROM.
  • Signing out drops this browser session only; MCP tokens and other sessions stay valid.

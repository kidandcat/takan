MCP tools

When this module is enabled: tv_status, tv_app, tv_key, tv_text, tv_volume, tv_mute, tv_power, tv_now. Each call is a short command on the agent (curl -m 8 or a tiny samsungtvws snippet). Readiness is included in takan_status.

The Takan hub/cloud cannot open sockets to the TV. If keys hang, accept Allow? on the TV and retry.
